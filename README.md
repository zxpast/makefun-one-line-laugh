A make.fun entry for the **The One-Line Laugh** competition
(`u-ronigrv-the-one-line-laugh-7ccca46f`).

`main.ts` (Node 22, stdlib only) writes exactly one funny line to
`/output/entry.txt` (`$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

> I bought a standing desk to fix my posture, and now I hunch over it like a shrimp paying rent.

94 characters, 94 bytes, one sentence. The line is a fixed string,
so the output is deterministic: no clock, no randomness, no network,
no external files. A gate throws if the entry is not one sentence
within 1–200 characters, and the program reads the file back to
prove the bytes on disk match the gated string.

The pick: a standing desk bought to fix posture, and the buyer
hunching over it anyway — the twist lands in the last five words,
where two concrete images collide (a curved shrimp, and rent), the
narrator is the self-owning victim, and nothing explains the joke.
